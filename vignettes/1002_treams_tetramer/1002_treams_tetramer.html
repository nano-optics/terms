Comparison between Treams and TERMS

03 September, 2024

  • External collective T-matrix

Objective

This example validates the results obtained with 2 different multiple-scattering codes based on the T-matrix method. It also illustrates how TERMS can import external T-matrices in the standard .tmat.h5 format.

The geometry consists of 4 dielectric spheres of varying radii arranged in a tetramer configuration. The cluster is chiral and has no particular symmetry, providing a good test case for a general T-matrix import. The collective T-matrix, collapsed as a single expansion about the origin, was computed using Treams, and is available in HDF5 format in the database.

The optical properties of this cluster of particles can be compared to the direct computation using multiple-scattering for the 4 independent spheres. This is similar to example 15_quadrimer, but here using an independent code for the collective T-matrix.

External collective T-matrix

The input file for TERMS is

ModeAndScheme 2 3
MultipoleCutoff 6 6 -3
Wavelength 300 700 200
Medium 1
OutputFormat HDF5 tetrahedron_external
TmatrixFiles 1
tetrahedron_nm.tmat.h5
Scatterers 1
TF1 0 0 0 270 0 0 0 1

Note that only vacuum_wavelength in nanometres is supported, and the wavelengths much match exactly. TERMS does not check the embedding medium, so it also the user’s responsibility to ensure they are identical.

and produces an output file tetrahedron_external.h5 storing the simulated results.

Internal calculation with multiple-scattering

In this second simulation, the cluster of particles is described by the 4 spheres, whose T-matrices are computed on-the-fly by TERMS using Mie theory. The simulation uses the following input file:

ModeAndScheme 2 3
MultipoleCutoff 6 6 -3
Wavelength 300 700 100
ScattererCentredCrossSections
Medium 1
OutputFormat HDF5 tetrahedron_internal
DielectricFunctions 1
"9.0d0 0.0d0"
Scatterers 4
DF1 -150 -86.60254 -61.23724 50
DF1  150 -86.60254 -61.23724 60
DF1    0 173.20508 -61.23724 70
DF1    0   0.00000 183.71173 80

and produces an output file tetrahedron_internal.h5 storing the simulated results.

Comparison

The two simulations show excellent agreement.

Note, however, that there are some challenges in this kind of simulation:

  • for the collective T-matrix approach, a sufficient multipolar order should be used to capture the full response of the cluster. This single-origin expansion cannot resolve near-field pattterns within the circumbscribed sphere of the cluster.
  • for the multiple-scatterer approach, note that the particles are relatively far apart (compared to the wavelength), and a relatively large number of multipoles may be required to obtain accurate results. It is also the case that some of the algorithms perform better than others (Stout vs Mackowski).
  • The absorption cross-section should be zero (and extinction should coincide with scattering), as the scatterers are non-absorbing. However, numerically some of the algorithms return spurious absorption in challenging configurations.
